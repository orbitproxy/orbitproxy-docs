# 查看访问日志

环境准备已经完成。不要再安装客户端，不要再执行 `npx skills add`。不要发布临时页面，不要为了查日志新建云端点。

CLI 不能开关访问日志采集，只能读已经记下的摘要。

1. `<orbitproxy> list --json`。没有云端点时告诉用户还没有可查的云端点，然后停下。
2. 只有一条时用它的 `proxy_id`。有多条时问用户要看哪一条。用户已经在消息里指定了服务或端口，就按那个匹配，不要再问。
3. `<orbitproxy> proxy logs --proxy-id <id> --json`。

一次最多 80 条，按时间从新到旧。把摘要告诉用户：时间、方法、路径、状态码、`error_code`。

- 403 `access_log_not_entitled`：当前套餐没有访问日志。停下并说明，不要改去安装客户端。
- 503 `access_log_unavailable`：访问日志存储未配置。停下并说明，不要改去安装客户端。
- `proxy_not_found`：这个云端点已经关掉，查不到日志。
