orbitproxy 是一个集成网关平台，可以连接你任何位置（云主机， localhost, 企业内网环境, IOT等）的任何服务，并为其提供企业级安全网关的流量观测，访问控制，及流量编排能力。

使用 orbitproxy API 网关，你可以在没有安全运维团队且没有服务器域名的情况下快速发布你的产品(无论你的产品在本地笔记本还是内网环境)，也可以将 orbitproxy 作为你已有项目的流量入口（traffic door）去替代 nginx, caddy，traefik，envoyproxy 等需要繁琐配置的云原生网关

而 MCP 网关是 orbitproxy 用于管理对 MCP 服务器访问的解决方案。它充当 MCP 客户端和 MCP 服务器之间的保护机制，处理身份验证、提供访问控制和日志记录。
