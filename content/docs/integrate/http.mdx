以下是预览用的接口形状，正式 OpenAPI 接入后会变成可执行 Playground。

## 创建 HTTP 入口

```bash
curl -X POST https://api.orbitproxy.com/v1/endpoints \
  -H "Authorization: Bearer $ORBITPROXY_AUTHTOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "http",
    "upstream": "http://127.0.0.1:5173",
    "region": "ap-east"
  }'
```

```json
{
  "id": "ep_1a2b3c",
  "url": "https://demo.orbitproxy.dev",
  "type": "http",
  "status": "online"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | string | 入口类型：`http` 或 `tcp` |
| `upstream` | string | 上游地址，例如 `http://127.0.0.1:5173` |
| `region` | string | 边缘区域，默认 `ap-east` |
