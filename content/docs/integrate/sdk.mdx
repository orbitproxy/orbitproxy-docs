不想单独开 CLI 时，用 SDK 在应用启动时连接控制面。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `ORBITPROXY_AUTHTOKEN` | 控制台签发的鉴权 token |
| `ORBITPROXY_MACHINE_KEY` | 机器身份，用于会话恢复 |
| `ORBITPROXY_API_URL` | 控制面地址 |

## Next.js

在 `instrumentation.ts` 里连接，不要 `await` 完整握手，避免挡住 `next dev` Ready。

```ts
export async function register() {
  if (process.env.NEXT_RUNTIME === "edge") return

  const machineKey = process.env.ORBITPROXY_MACHINE_KEY
  const authtoken = process.env.ORBITPROXY_AUTHTOKEN
  const apiUrl = process.env.ORBITPROXY_API_URL
  if (!machineKey || !authtoken || !apiUrl) return

  const { connect } = await import("@orbitproxysdk/core")
  void connect({ machineKey, authtoken, apiUrl }).then((svc) => {
    console.log("[orbitproxy] connected", { sessionId: svc.sessionId })
  })
}
```

<Callout type="warn">
  用 `@orbitproxysdk/core`，不要走会检测 `process.send` 后直接 no-op 的 Next 适配路径。
</Callout>
