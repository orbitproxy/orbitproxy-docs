---
title: 自定义响应
description: 按状态码替换网关返回的系统异常页面，或透传上游的原始响应。
---

<PolicyTag scope="api" />

自定义响应策略按状态码替换 orbitproxy 网关返回的系统异常页面。规则命中的状态码会返回规则中配置的响应头和响应内容，而不是系统默认页面。规则也可以选择透传，保留内网服务或 Edge 返回的原始响应。

## 配置参考

### 配置字段

<DocsTable>

| 字段 | 说明 |
| --- | --- |
| 规则名称 | 规则的名称，用于区分同一云端点上的多条规则 |
| 响应方式 | 「配置自定义内容」或「透传原始响应」。选择透传时不替换该状态码的页面，也不需要填写响应内容，不进入审核。当前订阅不包含自定义响应页面权益时，只能选择透传 |
| 状态码 | 可选择 `403`、`404`、`502`、`503`、`504`、`590`（维护中），或选择「其他」后填写 `100` 至 `599` 之间的状态码。同一云端点上，同一个状态码只允许存在一条规则 |
| 响应 Header | 自定义响应的响应头，默认包含 `content-type: text/html; charset=utf-8` |
| 响应 Body | 自定义响应的内容，上限为 128KiB。选择「配置自定义内容」时，响应 Header 和响应 Body 不能同时为空 |

</DocsTable>

## 行为

### 系统异常页面

未配置自定义响应时，网关对以下状态码返回 orbitproxy 的系统异常页面。

<DocsTable>

| 状态码 | 说明 |
| --- | --- |
| `403` | 当前请求被网关安全策略拒绝，无法继续访问 |
| `404` | 当前请求的内容未找到，无法继续访问 |
| `502` | 网关无法从上游服务获得有效响应，无法继续访问 |
| `503` | 当前服务暂时不可用，无法继续访问 |
| `504` | 当前请求等待上游服务响应超时，无法继续访问 |
| `590` | 服务正在维护中，请耐心等待，如有特殊请求请联系官方客服 |

</DocsTable>

### 替换和透传

- 配置自定义内容：规则审核通过后，该状态码的系统异常页面被规则中的响应头和响应内容替换。
- 透传原始响应：该状态码不被替换，访问方收到内网服务或 Edge 返回的原始响应。

### 内容审核

选择「配置自定义内容」的规则在提交后进入审核，审核状态为审核中，审核通过后才会生效。审核通常在 1 小时内完成。

修改规则的状态码、响应方式、响应 Header 或响应 Body 后，规则会重新进入审核。仅修改规则名称不会触发重新审核。

## 示例

为 `502` 配置自定义内容。响应方式选择「配置自定义内容」，状态码选择 `502`，响应 Header 保持默认值，响应 Body 填写如下内容。

```html
<!doctype html>
<html lang="zh-CN">
<head>
    <meta charset="utf-8" />
    <title>502</title>
</head>
<body>
    服务暂时不可用，请稍后重试。
</body>
</html>
```

规则审核通过后，网关返回 `502` 时，访问方收到的是上述页面，而不是 orbitproxy 的系统异常页面。

<img src="/images/custom-response-page.jpg" alt="审核通过后返回的自定义页面" className="docs-shot" />

维护期间使用 `590` 状态码展示自定义页面的场景，见[快速让生产环境服务进入维护熔断模式](/docs/gateway/use-cases/maintenance-mode)。
