<PolicyTag scope="common" />

访问日志策略在云端点上记录经过网关的请求，记录的内容由采集级别决定。该策略不会拦截请求，流量仍然转发到上游服务。

## 配置参考

### 适用范围

API 网关的 HTTPS 云端点和 TCP 云端点，以及 MCP 网关。

### 配置字段

<DocsTable>

| 字段 | 说明 |
| --- | --- |
| 是否启用 | 启用或停用该云端点的访问日志 |
| 采集级别 | 「元数据」「请求头 / 响应头」「请求体 / 响应体」，可多选。级别越高，记录的内容越多 |
| 日志 Body 上限 | 仅在采集级别包含请求体 / 响应体时可配置。最低 1KB，默认 4KB，最高值由当前订阅决定。超过上限的 Body 内容会被放弃 |
| 保留天数 | 日志的保留时间，可选 1 天、3 天或 7 天，可选范围由当前订阅决定。超过保留天数的日志会被清除 |

</DocsTable>

## 行为

三个采集级别逐级叠加。

- 元数据：记录状态码、路径等基础信息。
- 请求头 / 响应头：在元数据之外，记录完整的请求头和响应头。
- 请求体 / 响应体：在以上内容之外，记录请求体和响应体。Body 按日志 Body 上限采集，超出上限的部分不会被记录。

## 示例

采集级别选择「请求体 / 响应体」，日志 Body 上限保持默认的 4KB，保留天数选择 3 天。保存后，该云端点收到的请求会被记录，可以在<a href="https://dashboard.app.orbitproxy.cloud/observability/request-logs" target="_blank" rel="noopener noreferrer">云端点访问日志</a>中查看每一次请求的详情。请求体和响应体中超过 4KB 的部分不会被记录，日志在 3 天后被清除。
