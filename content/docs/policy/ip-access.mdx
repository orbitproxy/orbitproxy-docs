---
title: IP访问控制
description: 按来源 IP 允许或拒绝访问云端点。
---

只让可信网络打到公网入口，或拦掉已知恶意来源。规则挂在云端点上，上游不用改。

## 在控制台怎么配

1. 打开对应 API、Webhook 或 MCP 云端点，切到 **流量策略**
2. 展开 **IP访问控制**，点 **添加规则**
3. 填 **规则名称**
4. **策略模式** 选「拒绝名单（黑名单）」或「允许名单（白名单）」
5. 在 **IP / CIDR 列表** 里加地址，例如 `192.168.1.0/24` 或单 IP `10.0.0.1`
6. 保存

白名单只放行列表里的来源，其余全部拒绝。黑名单相反：列表里的来源被拒绝，其余放行。
