<PolicyTag scope="mcp" />

MCP 访问控制策略按访问密钥授权调用方可以使用的 MCP Endpoint 和 Tools，并可进一步禁止指定类别的 SQL 语句和文件操作。未获授权的调用在网关终止，不会到达内网 MCP 服务，上游 MCP 服务无需修改。

## 配置参考

### 执行阶段

MCP 调用到达网关时执行。

### 配置字段

<DocsTable>

| 字段 | 说明 |
| --- | --- |
| 规则名称 | 规则的名称，用于区分同一云端点上的多条规则 |
| 访问密钥 | 被授权的调用方，可选择一个或多个。访问密钥来自 [API 访问密钥](/docs/policy/api-key)策略中已创建的凭证，同一份授权可以同时授予多个访问密钥 |
| Endpoint 权限 | 一组或多组授权，每一组针对一个 Connector，包含以下配置项 |

</DocsTable>

### Endpoint 权限

<DocsTable>

| 配置项 | 说明 |
| --- | --- |
| Connector | 被授权访问的 MCP Endpoint。同一条规则中，每个 Connector 只能出现一次 |
| Tools | 允许调用的 Tool，至少选择一个。需要填写具体的 Tool 名称，不支持通配符 `*` |
| 禁止的 SQL 语句 | 可选。选择需要禁止的语句类别：查询（`SELECT`）、插入（`INSERT` / `REPLACE`）、更新（`UPDATE`）、删除（`DELETE`）、DDL（`CREATE` / `ALTER` / `DROP`）。仅对 SQL 类 Connector 生效 |
| 禁止的文件操作 | 可选。选择需要禁止的操作：读、写、移动。仅对文件系统类 Connector 生效 |
| 开放路径 | 可选，路径前缀列表。配置后，文件操作涉及的路径必须位于其中某个前缀之下。仅对文件系统类 Connector 生效 |

</DocsTable>

## 行为

网关根据请求携带的访问密钥识别调用方，并依次进行以下判断。任一步骤不通过，请求在网关终止，不会进入内网 MCP 服务。

1. 该访问密钥在目标 Connector 上没有授权，请求被拒绝。
2. 调用的 Tool 不在授权的 Tools 中，请求被拒绝。
3. 调用的是 SQL 类 Tool，且配置了禁止的 SQL 语句时，网关解析本次语句的类别。语句类别属于禁止的类别，或者无法识别、属于权限管理类时，请求被拒绝。
4. 调用的是文件类 Tool，且配置了禁止的文件操作时，本次操作属于禁止的操作，请求被拒绝。配置了开放路径时，请求中的路径不在任何开放路径之下，同样被拒绝。

全部通过的请求转发到内网 MCP 服务。

### 其他限制

同一个访问密钥在同一个 Connector 上，只能存在一条启用状态的授权。重复授权会导致规则无法保存。

## 示例

访问密钥选择 `cursor-readonly`，Connector 选择内网 MySQL 的 MCP，Tools 只选择查询类的 `mysql_query`，禁止的 SQL 语句选择插入、更新、删除和 DDL。

使用该访问密钥发起的查询语句转发到内网 MCP 服务。调用未授权的 Tool，或发出 `DELETE`、`DROP` 等语句时，请求在网关终止，内网 MCP 服务收不到该请求。

场景见 [Agent 受控访问内网 MCP](/docs/mcp-gateway/use-cases/connect-internal)。
