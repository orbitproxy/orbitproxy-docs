BasicAuth 基础鉴权策略在云端点上强制要求 HTTP Basic Auth。携带正确用户名和密码的请求转发到上游服务，其余请求直接返回 `401 Unauthorized`，不会到达上游服务。

## 配置参考

### 执行阶段

请求到达网关时执行。

### 配置字段

<DocsTable>

| 字段 | 说明 |
| --- | --- |
| 规则名称 | 规则的名称，用于区分同一云端点上的多条规则 |
| Credentials | 允许通过的凭证，格式为 `username:password`，每行一组。密码长度为 8 至 128 个字符 |

</DocsTable>

## 行为

网关按 [RFC 7235](https://datatracker.ietf.org/doc/html/rfc7235) 校验 HTTP Basic Authentication。请求中的凭证与已配置的 `username:password` 一致时，请求继续转发，最终到达上游服务；不一致时，请求在网关终止，并返回 `401 Unauthorized`。

### 其他限制

密码最短 8 个字符，最长 128 个字符。`username:password` 中包含多个冒号时，第一个冒号是用户名与密码的分隔符，其后的内容全部属于密码。

### 校验过程

- 请求必须携带 `Authorization` 请求头，格式为 `Authorization: Basic <credentials>`。其中 `<credentials>` 是 `username:password` 的 Base64 编码。
- 校验通过后，请求继续转发到上游服务。
- 校验失败时返回 `401`。浏览器收到该响应后会显示原生的用户名和密码输入框，调用方可以重新提交凭证。

## 示例

先对 `username:password` 做 Base64 编码。`user:password1` 的编码结果为 `dXNlcjpwYXNzd29yZDE=`。

```bash
curl https://<云端点域名>/ \
  -H "Authorization: Basic dXNlcjpwYXNzd29yZDE="
```

凭证正确时，网关将请求转发到上游服务，并返回上游服务的响应。

请求未携带 `Authorization` 请求头，或用户名、密码不正确时，网关返回 `401 Unauthorized`，浏览器显示登录框。
