---
title: 添加/移除HTTP Header
description: 在转发前后添加或移除 HTTP Header。
---

在请求转到上游之前，或响应回到调用方之前，添加或移除 HTTP Header。改头不会把请求拦在网关，流量仍按云端点配置转发。

一条规则只做一件事，由作用方向决定：追加请求头、移除请求头、追加响应头，或移除响应头。

## 配置参考

追加或移除请求头时，在请求到达网关、转发到上游之前执行。追加或移除响应头时，在上游返回之后、响应送回调用方之前执行。

## 行为

- **追加请求头**：把指定字段加到进入网关的请求上，再转发到上游。
- **移除请求头**：从进入网关的请求上拿掉指定字段，上游看不到这个头。
- **追加响应头**：把指定字段加到上游返回的响应上，再送回调用方。
- **移除响应头**：从上游返回的响应上拿掉指定字段，调用方看不到这个头。

作用范围选「整个 Proxy」时，该云端点上的请求都适用。选「指定路径」时，只命中你填的前缀或精确路径。

## 示例

追加请求头，作用范围选整个 Proxy，Header 名 `x-request-id`，值为 `edge`。上游收到的请求里会带上 `x-request-id: edge`。

移除请求头，Header 名 `x-trace-id`。调用方即使带了这个头，转发到上游时也会被拿掉。

追加响应头，Header 名 `access-control-allow-origin`，值为 `*`。调用方收到的响应里会带上这个 CORS 头，上游不用改代码。
