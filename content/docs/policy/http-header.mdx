---
title: 添加/移除HTTP Header
description: 在转发前后添加或移除 HTTP Header。
---

给上游补标识、埋点字段，或在出网前拿掉不该暴露的头。可以作用在请求上，也可以作用在响应上。

## 在控制台怎么配

1. 打开对应云端点，切到 **流量策略**
2. 展开 **添加/移除HTTP Header**，点 **添加规则**
3. 填 **规则名称**
4. **作用范围** 选「整个 Proxy」，或「指定路径」后再加前缀 / 精确路径
5. **作用方向** 选「追加请求头」「移除请求头」「追加响应头」或「移除响应头」
6. 在 **Header** 里填字段名；追加时还要填值
7. 保存
