---
title: API 访问密钥
description: 要求请求携带 API Key，没带或带错的请求在网关被拦截。
---

给调用方发一把可撤销的密钥。请求必须在指定请求头里带上合法密钥，才会转到上游。没带，或带错，请求在网关被拦截，不会打到内网。

## 配置参考

这条策略在请求到达网关时执行。

## 行为

网关读取你配置的请求头，把里面的值和凭证里的密钥比对。

- 值与某一条密钥一致，请求继续转发到上游。
- 没有这个请求头，或值对不上任何一条密钥，请求在网关结束。

作用范围选「整个 Proxy」时，该云端点上的请求都要带密钥。选「指定路径」时，只校验命中的前缀或精确路径。

密钥可以撤销。从凭证里删掉某一条之后，再带这把密钥的请求会被拦截。

## 示例

请求头用默认的 `x-api-key`，凭证里的密钥是 `你在控制台填的密钥`。

```bash
curl https://你的云端点/v1/orders \
  -H "x-api-key: 你在控制台填的密钥"
```

密钥正确时，网关把请求转到上游，并返回上游的响应。不带 `x-api-key`，或值不对时，请求在网关被拦截。
