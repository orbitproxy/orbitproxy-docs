1. 为各种云端环境（如公司测试环境，PROD生产环境）的内网MCP提供访问支持，让开发或者运维本地 AI Agent安全调用云端MCP，提高开发排障运维效率
2. 环境级运维解决方案，orbitproxy MCP Composer 允许聚合某一个环境上下文中的所有MCP服务，串成一套完整工作流， 将AI Agent视角从单个MCP 拔高到整套环境中的所有MCP进行，同时提供集中做身份接入、对AI Agent 执行Tool 授权和敏感操作拦截， 以及带来AI 的完整调用可视化日志

## 本地 AI Agent 安全调用云端内网 MCP

公司测试环境、PROD 生产环境里的 MCP 通常跑在 VPC 内网，本机 Cursor 等 Agent 到不了。在控制台为对应环境建 **MCP 云端点**，开发或运维就能在自己电脑上<span className="docs-em">安全调用云端内网 MCP</span>，做联调、排障和运维，不必把内网 MCP 裸奔到公网。

## 环境级 MCP Composer 聚合 & AI 调用全链路可观测

orbitproxy MCP Composer 把某一个环境上下文中的 Redis、MySQL、Docker、系统日志等 MCP 收成<span className="docs-em">一套完整工作流</span>，把 AI Agent 的视角从单个 MCP 拔高到整套环境。集中做身份接入，按身份源对 Agent 执行的 Tool 授权，并可拦截敏感 SQL 或文件操作，<span className="docs-em">同时留下 AI 的完整调用可视化日志</span>。
