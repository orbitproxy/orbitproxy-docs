连接你任何位置(本地 localhost, 企业内网环境， 云主机， Nas等)的HTTP / TCP 服务，并为其提供统一的认证鉴权， 访问控制，以及强大的可观测性

orbitproxy API网关可以替代你的 nginx / caddy 成为你的云网关系统，让你再无需部署 clickhouse, elk等日志集群服务的情况下快速获得强大的流量观测能力， 也可以通过界面化的配置快速为你的产品服务叠加访问控制，认证鉴权，流量限速， 负载均衡等高阶扩展能力，降低团队运维门槛，让你的服务永不掉线, 保护你的服务不受DDOS, 端口扫描， 请求重放，中间人攻击等恶意攻击

另一方面，无论你的前端项目和后端服务是工作在 localhost 笔记本电脑，亦或者云主机内网服务器，orbitproxy都能提供公网访问能力， 这使得用户可以轻松利用 orbitproxy API Gateway 做到:

- localhost接收微信支付等第三方 webhook 回调
- 无需公网域名 & 云主机服务器 快速发布上线产品
- 企业内网演示环境快速分享给外网客户
- 我的世界幻兽帕鲁等游戏联机
- 其他任何只要支持网络套接字的HTTP TCP服务
