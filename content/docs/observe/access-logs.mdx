---
title: 访问日志
description: 查看请求链路、状态码、耗时，必要时导出 raw request。
---

每个入口（API、Webhook、MCP Tool）都会留下访问记录，覆盖路径、状态、耗时和关键字段。

## 能看到什么

- 方法、路径、状态码、耗时
- 来源 IP、区域、入口 ID
- Webhook Provider 与验签结果
- MCP tool 名、run ID、是否被拦截
- 可选 raw request，方便联调和事后审计

<Callout type="info">
  日志导出到外部存储或分析平台仍在规划中。当前先在控制台检索和下载。
</Callout>
