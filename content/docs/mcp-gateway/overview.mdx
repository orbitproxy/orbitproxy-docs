连接你任何形态（Streamable HTTP, Stdio），任何位置（远程， 内网， localhost本地）的MCP 服务，并为其提供统一的认证鉴权， 访问控制，以及强大的可观测性

orbitproxy MCP网关既是连接MCP服务和AI Agent的桥梁，也同时可以做到企业级认证鉴权和访问控制以及对AI Agent 的调用进行每一次深度追踪，让AI Agent 的操作不再是黑盒，同时可以做到限制AI Agent的异常操作和敏感行为，对高危行为进行拦截和告警

直接连接到 MCP 服务器时，每个AI Agent都需要为每台服务器单独配置凭据。而使用 MCP 网关，客户端只需向 orbitproxy 进行一次身份验证。网关会处理所有已配置MCP 服务的凭据注入、权限检查和请求日志记录。
